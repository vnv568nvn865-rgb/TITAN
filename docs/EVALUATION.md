# TITAN Evaluation

TITAN needs objective evaluation.

## Benchmark Families

- Code generation
- Code completion
- Bug fixing
- Unit-test creation
- Repository-level changes
- Refactoring
- Build/debug tasks
- Tool-use tasks
- Long-context code understanding
- Software architecture

## Verification

Where possible, use executable tests, compilers, static analysis, and repository-level checks.

## Version Comparison

Every candidate model should be evaluated against a stable benchmark set and a newly created challenge set.

Metrics should include both success rate and failure severity, not only token-level similarity.
