# Decision 0001 — Project Direction

## Decision

TITAN is intended to become an independently developed AI software-engineering system rather than a frontend that depends on a commercial external model for its core intelligence.

## Rationale

The project goal is ownership of the model/system behavior, training process, memory, tools, evaluation, and improvement loop.

External models can still be used as temporary research tools, baselines, or development aids when explicitly documented.

## Status

Accepted.
