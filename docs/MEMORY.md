# TITAN Memory

## Short-Term

Stores the active conversation/task context.

## Project Memory

Stores stable facts about the current repository:

- Structure
- Dependencies
- Architecture
- Important files
- Decisions
- Known issues
- Current task state

## Experience Memory

Stores reusable engineering experiences:

- Problem
- Environment
- Attempt
- Result
- Failure reason
- Successful fix
- Verification
- Confidence / evidence

Memory should be searchable and should avoid blindly storing every interaction.
