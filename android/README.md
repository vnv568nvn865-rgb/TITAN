# طبقة Android و llama.cpp

## الهدف

تشغيل نموذج TITAN محليًا على Android باستخدام محرك llama.cpp وملف نموذج بصيغة GGUF.

## المكونات

طبقة Android مسؤولة عن:

- تحميل ملف GGUF.
- تهيئة محرك الاستدلال.
- إرسال النص إلى النموذج.
- استقبال التوليد.
- إعادة النتيجة إلى طبقة Python أو طبقة التطبيق حسب بنية المشروع.

## النموذج المستهدف

النموذج الأول للاختبار:

Qwen2.5-Coder-1.5B-Instruct

صيغة النموذج:

GGUF

التكميم الأول المقترح:

Q4_K_M

## متطلبات المحرك

يجب أن يدعم المحرك:

- تحميل GGUF.
- CPU inference.
- التحكم في عدد الخيوط.
- تحديد حجم السياق.
- تحديد عدد الرموز الناتجة.
- إيقاف التوليد.
- قراءة الأخطاء.
- تحرير الذاكرة عند إغلاق النموذج.

## الذاكرة

يجب عدم تحميل النموذج أكثر من مرة دون حاجة.

يجب تحرير الموارد عند انتهاء الجلسة.

يجب أن تكون إعدادات:

- عدد الخيوط.
- حجم السياق.
- عدد الرموز الناتجة.

قابلة للتعديل.

## الأداء

يجب قياس:

- زمن تحميل النموذج.
- زمن أول رمز.
- سرعة التوليد.
- استهلاك الذاكرة.
- استقرار التطبيق أثناء التوليد.

## قاعدة مهمة

لا تعتبر TITAN النموذج متصلًا فعليًا حتى يتم تحميل ملف GGUF وتشغيل استدلال حقيقي عبر llama.cpp.

الكود التجريبي أو الواجهة الوهمية لا تعتبر تشغيلًا حقيقيًا للنموذج.
