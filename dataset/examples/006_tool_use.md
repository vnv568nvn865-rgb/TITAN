# عينة التدريب 006 — استخدام الأدوات

## المعرّف
006_tool_use

## الفئة
استخدام الأدوات

## مستوى الصعوبة
متوسط

## المهمة
يوجد مشروع Python يحتوي على ملف باسم calculator.py.

المطلوب من المهندس إضافة دالة لحساب حاصل ضرب رقمين، ثم تشغيل الاختبارات للتأكد من أن التعديل يعمل.

## السياق

المشروع يحتوي على الكود التالي:

def add(a, b):
    return a + b

## المتطلبات

1. فحص الملف قبل تعديله.
2. إضافة دالة باسم multiply.
3. عدم حذف الدالة add.
4. تشغيل الاختبارات بعد التعديل.
5. معالجة أي خطأ يظهر أثناء الاختبار.

## الخطة

1. قراءة calculator.py.
2. فهم الكود الموجود.
3. إضافة الدالة الجديدة.
4. حفظ التعديل.
5. تشغيل الاختبارات.
6. قراءة نتيجة الاختبارات.
7. إصلاح أي مشكلة تظهر.
8. إعادة تشغيل الاختبارات.

## تسلسل استخدام الأدوات

### الخطوة الأولى — قراءة الملف

يتم فتح calculator.py وقراءة محتواه قبل إجراء أي تعديل.

النتيجة:

تم العثور على الدالة add.

### الخطوة الثانية — تعديل الملف

تمت إضافة:

def multiply(a, b):
    return a * b

مع الحفاظ على الدالة add.

### الخطوة الثالثة — تشغيل الاختبارات

يتم تشغيل مجموعة الاختبارات الخاصة بالمشروع.

النتيجة:

اختبارات الدالة add نجحت.

اختبار الدالة multiply نجح.

### الخطوة الرابعة — التحقق

تم التأكد من أن:

multiply(2, 3) تعطي 6.

multiply(5, 4) تعطي 20.

multiply(0, 10) تعطي 0.

## النتيجة النهائية

تم تعديل المشروع بنجاح دون حذف الوظائف الموجودة.

تم استخدام الأدوات بالترتيب:

قراءة → تعديل → اختبار → قراءة النتيجة → تحقق.

## الدروس المستخلصة

1. يجب قراءة الملف قبل تعديله.
2. لا يجب تعديل الملفات دون فهم حالتها الحالية.
3. يجب تشغيل الاختبارات بعد التعديل.
4. نتيجة الأداة يجب أن تؤثر في الخطوة التالية.
5. لا يكفي افتراض نجاح التعديل.
6. استخدام الأدوات جزء من عملية حل المشكلة وليس مجرد تنفيذ أوامر.
