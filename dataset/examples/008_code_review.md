## الفئة
مراجعة الكود

## مستوى الصعوبة
متوسط

## المهمة
راجع الكود التالي وحدد المشاكل الموجودة فيه قبل إجراء أي تعديل.

## الكود

def get_user(users, user_id):
    for user in users:
        if user["id"] == user_id:
            return user

    return None


def print_user(users, user_id):
    user = get_user(users, user_id)

    print("اسم المستخدم:", user["name"])
    print("العمر:", user["age"])

## المتطلبات

1. اكتشاف الأخطاء المحتملة.
2. تحديد سبب كل مشكلة.
3. عدم تعديل الكود قبل فهم المشكلة.
4. اقتراح إصلاحات بسيطة.
5. التأكد من أن الإصلاحات لا تغير السلوك الصحيح.

## التحليل

الدالة get_user تعيد None عندما لا تجد المستخدم.

لكن print_user تفترض أن النتيجة تحتوي دائمًا على بيانات المستخدم.

إذا لم يتم العثور على المستخدم، فإن محاولة تنفيذ:

user["name"]

ستؤدي إلى خطأ لأن user تساوي None.

## المشكلة

يوجد خطأ محتمل من نوع التعامل مع قيمة غير موجودة.

الحالة التي تسبب المشكلة:

users = [
    {"id": 1, "name": "Ali", "age": 20}
]

user_id = 5

في هذه الحالة لا يوجد مستخدم بالمعرف 5.

## الإصلاح المقترح

يجب التحقق من قيمة user قبل الوصول إلى عناصرها.

## التنفيذ المقترح

def get_user(users, user_id):
    for user in users:
        if user["id"] == user_id:
            return user

    return None


def print_user(users, user_id):
    user = get_user(users, user_id)

    if user is None:
        print("المستخدم غير موجود.")
        return

    print("اسم المستخدم:", user["name"])
    print("العمر:", user["age"])

## التحقق

### حالة المستخدم الموجود

المدخل:

users = [
    {"id": 1, "name": "Ali", "age": 20}
]

user_id = 1

النتيجة المتوقعة:

اسم المستخدم: Ali
العمر: 20

الحالة:

نجاح

### حالة المستخدم غير الموجود

user_id = 5

النتيجة المتوقعة:

المستخدم غير موجود.

الحالة:

نجاح

## الدروس المستخلصة

1. يجب مراجعة الحالات التي يمكن أن تعيد قيمة فارغة.
2. يجب عدم افتراض نجاح البحث دائمًا.
3. يجب التحقق من القيم قبل استخدامها.
4. مراجعة الكود يجب أن تبحث عن الحالات التي قد تفشل، وليس فقط عن الأخطاء الموجودة في الحالة الطبيعية.
5. الإصلاح الجيد يعالج سبب المشكلة دون تغيير السلوك الصحيح.

## النتيجة النهائية

تم اكتشاف أن print_user لا تتعامل مع حالة عدم العثور على المستخدم.

تمت إضافة عملية تحقق قبل الوصول إلى بيانات المستخدم.
